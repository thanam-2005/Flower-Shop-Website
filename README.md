# 🌸 Thans Petals — Flower Shop Website

A modern, responsive, and user-friendly **Flower Shop Website** designed to provide an attractive online shopping experience for browsing and exploring flowers.

The website is developed using **HTML, CSS, and JavaScript**, with interactive features such as shopping cart, wishlist, search, dark mode, gallery, and contact form.

## 🌐 Live Demo

**[🔗 Visit Thans Petals — Live Website](https://thanam-2005.github.io/Flower-Shop-Website/)**

## ✨ Features

* 🌸 Modern and visually appealing UI
* 📱 Responsive design for different screen sizes
* 🛒 Interactive shopping cart
* ❤️ Wishlist functionality
* 🔍 Product search
* 🌙 Dark mode
* 🖼️ Flower gallery
* 📞 Contact form

## 🖥️ Website Sections

### 🏠 Home

Attractive landing section introducing the flower shop and its products.

### 🌷 Flower Collection

Displays the available flowers with an organized and visually appealing layout.

### 🛒 Shopping Cart

Allows users to add and manage selected products.

### ❤️ Wishlist

Provides an option to save preferred flowers for later.

### 🔍 Search

Enables users to quickly find flowers or products.

### 🌙 Dark Mode

Allows users to switch between light and dark themes.

### 🖼️ Gallery

Showcases flower images through a dedicated gallery section.

### 📞 Contact

Provides a contact form for users to send enquiries.
